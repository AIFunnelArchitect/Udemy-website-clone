# Udemy Clone

A simple **Udemy-inspired online learning platform UI** built using **HTML and CSS**. This project was created to practice and demonstrate fundamental front-end development skills, including webpage structure, styling, layouts, navigation, and responsive design concepts.

## Features

* Udemy-inspired homepage design
* Navigation bar with search functionality UI
* Course categories and course cards
* Course information and pricing sections
* Clean and structured page layout
* Responsive styling using CSS

## Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling, layouts, and visual design
* Flexbox** - Box model, Flex-grow, flex-basics

## Purpose

This project was built as a **front-end practice project** to improve my understanding of HTML and CSS by recreating the look and feel of a popular e-learning platform.

> **Note:** This is a learning project and is not affiliated with or connected to Udemy.
